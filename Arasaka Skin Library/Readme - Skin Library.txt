SKIN LIBRARY


SKIN FILES ARE REQUIRED BY ARASAKA CYBERARMS!
Each cyberarm type has its own skin file, and they are divided between male and female, left and right arms. If you want to change skins, remember to delete the old skin files. It is highly recommended you install the mod with Vortex for easier installation and management.


SKINS INCLUDED IN THIS FOLDER:

Default = Skins for Arasaka Default arms, and right arm when using Launcher cyberware.
Gorilla = Skins for Arasaka Gorilla arms.
Launcher = Skins for Arasaka Launcher arms.
Mantis = Skins for Arasaka Mantis arms.
Monowire = Skins for Arasaka Monowire arms.
