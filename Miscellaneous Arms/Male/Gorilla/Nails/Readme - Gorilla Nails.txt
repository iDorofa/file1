GORILLA NAILS


All the nail colors for use together with the Gorilla Bare Arms. There is an image in the images folder that shows what nail color has what number.

01 -- Basic light nails.
34 -- Basic dark nails.


The files should be placed in the "Cyberpunk 2077\mods\Arasaka Cyberarms\archives" folder. Only place the .archive files there, not the folders.
