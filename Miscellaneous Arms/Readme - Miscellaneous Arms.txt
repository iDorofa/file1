MISCELLANEOUS ARMS


A collection of miscellaneous arms to use individually or together with the Arasaka Cyberarms. All arms have disabled shadows to prevent double shadows from arms. Files are located in a folder called "No Shadows" when that is the only difference from the default cyberarms.


ARMS INCLUDED IN THIS FOLDER:

Default = Replaces your normal unmodded arms, and right arm when using Launcher cyberware.
Gorilla = Replaces Gorilla cyberware arms, bought from ripper docs.
Launcher = Replaces Launcher cyberware left arm, bought from ripper docs.
Mantis = Replaces Mantis cyberware arms, bought from ripper docs.
Monowire = Replaces Monowire cyberware arms, bought from ripper docs.

DEFAULT:
Gorilla Arms -- Gorilla arm look for Default arms.
Gorilla Arms - No Knuckles -- Gorilla arm look without knuckles.
No Shadows -- Right arm only, removes double shadows when used with Launcher cyberware.
Shaitan Arms -- The metal arms of Shaitan, that you meet during one of the missions with Johnny.

GORILLA:
Bare Arms -- Bare Gorilla arms that can use the nails from the Nails folder.
Gorilla Arms - No Shadows -- Default Gorilla arms with disabled shadows.
Gorilla Arms - No Shadows No Knuckles -- Default Gorilla arms with removed knuckles.
Gorilla Arms Red - No Shadows -- Default Gorilla arms with red forearms.
Gorilla Arms Red - No Shadows No Knuckles -- Default Gorilla arms with red forearms and removed knuckles.
Nails -- Nails for the Bare Arms, has all the default nail colors.
Shaitan Arms - Gorilla version of Shaitan metal arms.

LAUNCHER:
Gorilla Arm -- Gorilla arm look for Launcher arm.
Gorilla Arms - No Knuckles -- Gorilla arm look without knuckles.
No Shadows -- Default Launcher arm with disabled shadow.

MANTIS:
Bare Arms - Closed -- Bare Mantis arms that do not open. Requires a closed blade from the Blade Library.
Mantis Arms - Closed -- Default Mantis arms that do not open. Requires a closed blade from the Blade Library.
Mantis Arms - No Shadows -- Default Mantis arms with disabled shadows. Can use custom open blades.
Shaitan Arms -- Mantis version of Shaitan metal arms. Opens up like the default Mantis arms.

MONOWIRE:
No Shadows -- Default Monowire arms with disabled shadows.
No Shadows No Wire Grip -- Default Monowire arms with removed wire grip decals.

F = Female
M = Male
L = Left arm
R = Right arm


The files should be placed in the "Cyberpunk 2077\archive\pc\mod" folder. Only place the .archive files there, not the folders.
