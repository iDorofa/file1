REMOVE NAILS


SAME NAIL MESHES ARE USED ON ALL ARMS!
Removing nails will remove them from all arm types for that arm. That is because they all use the same nail meshes. The Arasaka Cyberarms should have nails removed, or the nails will clip with the hands. Nails were previously removed when ever an Arasaka Cyberarm was installed, but has been made in to a separate mod to be easier to toggle, instead of having to remove all arm mods.


FILES INCLUDED IN THIS FOLDER:

aa_Remove_Nails_F_L - Removes nails from female left hand.
aa_Remove_Nails_F_R - Removes nails from female right hand.

aa_Remove_Nails_M_L - Removes nails from male left hand.
aa_Remove_Nails_M_R - Removes nails from male right hand.


The files should be placed in the "Cyberpunk 2077\archive\pc\mod" folder. Only place the .archive files there, not the folders.
