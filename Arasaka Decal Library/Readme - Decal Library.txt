DECAL LIBRARY


DECALS REPLACE THE WEAPON GRIP CYBERWARE!
At the beginning of the game, the ripper doc Viktor will install the first Weapon Grip cyberware for your character. Weapon Grips include the Ballistic Coprocessor and Smart Link. Decals will not work with the tattoo hand cyberware from Cassius, given to your character at a couple of points in the game.

ONLY ONE SIZE OF DECALS PER ARM!
While you can pick different decals sizes, you can only pick one size per arm. The decals will always be visible while having the Weapon Grip cyberware installed. Remember that when installing the Arasaka Cyberarms. The decals do not animate with arms that open up, so should not be used together with Arasaka Mantis Remade.

CUSTOM DECALS REQUIRE A MESH AND A TEXTURE!
In the Male and Female folders are all the decal meshes. If you pick the Custom option you will also need to install a texture from the Custom Textures folder.
