ZETATECH CYBERARMS


ALL ZETATECH ARMS REQUIRE A SKIN FILE!
You will find all skins in the Zetatech Skin Library folder. Each cyberarm type has its own skin file, and they are divided between left and right arms. It is highly recommended you install the mod with Vortex for easier installation and management.

CLOSED MANTIS ARMS REQUIRE A BLADE MOD!
For the Zetatech Mantis arms you need a blade for closed arms. They can be found in the Blade Library. You can pick different blades between left and right arms.


ARMS INCLUDED IN THIS FOLDER:

Default = Replaces the normal unmodded arms, and right arm when using Launcher cyberware.
Gorilla = Replaces Gorilla cyberware arms, bought from ripper docs.
Launcher = Replaces Launcher cyberware left arm, bought from ripper docs.
Mantis = Replaces Mantis cyberware arms, bought from ripper docs.
Monowire = Replaces Monowire cyberware arms, bought from ripper docs.

ALL CYBERARM TYPES:
Zetatech Arms -- The normal sized Zetatech Cyberarms.

F = Female
M = Male
L = Left arm
R = Right arm


The files should be placed in the "Cyberpunk 2077\archive\pc\mod" folder. Only place the .archive files there, not the folders.
