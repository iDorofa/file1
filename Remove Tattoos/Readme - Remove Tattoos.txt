REMOVE TATTOOS


ONLY FOR TATTOOS USING THE TATTOO MESHES!
This mod is compatible with custom tattoo texture mods that use the default meshes. It will remove tattoos from the arms of your character so that they do not clip with the Arasaka Cyberarms.

DOES NOT WORK WITH BIG OR SMALL BREASTS!
Because of problems with editing certain game files the female tattoos will only fit the default breast size. That means there will be some clipping with big and small breasts when topless. As all female tops use the default breast size there will not be a big or small version of this mod.


FILES INCLUDED IN THIS FOLDER:

aa_Remove_Tattoos_F - Removes tattoos on both arms, for female characters.
aa_Remove_Tattoos_F_L - Removes tattoos on female left arm.
aa_Remove_Tattoos_F_R - Removes tattoos on female right arm.

aa_Remove_Tattoos_M - Removes tattoos on both arms, for male characters.
aa_Remove_Tattoos_M_L - Removes tattoos on male left arm.
aa_Remove_Tattoos_M_R - Removes tattoos on male right arm.


The files should be placed in the "Cyberpunk 2077\archive\pc\mod" folder. Only place the .archive files there, not the folders.
