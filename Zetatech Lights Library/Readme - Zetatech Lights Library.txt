ZETATECH LIGHTS LIBRARY


LIGHTS FILES ARE REQUIRED BY ZETATECH CYBERARMS!
Zetatech cyberarms share lights files between cyberarm types. If you want to change lights, remember to delete the old lights files. It is highly recommended you install the mod with Vortex for easier installation and management.


LIGHTS INCLUDED IN THIS FOLDER:

Black Ops -- Default lights for the Black Ops skins.
Default -- Default lights.
Off -- Lights turned off.
Solid Orange -- Orange lights, not blinking.
Solid White -- White lights, not blinking.

F = Female
M = Male
L = Left arm
R = Right arm


The files should be placed in the "Cyberpunk 2077\archive\pc\mod" folder. Only place the .archive files there, not the folders.
