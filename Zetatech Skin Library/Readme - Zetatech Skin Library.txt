ZETATECH SKIN LIBRARY


SKIN FILES ARE REQUIRED BY ZETATECH CYBERARMS!
Each cyberarm type has its own skin file, and they are divided between left and right arms. If you want to change skins, remember to delete the old skin files. It is highly recommended you install the mod with Vortex for easier installation and management.


SKINS INCLUDED IN THIS FOLDER:

Default = Skins for Zetatech Default arms, and right arm when using Launcher cyberware.
Gorilla = Skins for Zetatech Gorilla arms.
Launcher = Skins for Zetatech Launcher arms.
Mantis = Skins for Zetatech Mantis arms.
Monowire = Skins for Zetatech Monowire arms.
