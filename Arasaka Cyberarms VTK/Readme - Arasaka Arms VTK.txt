ARASAKA CYBERARMS VTK


REQUIRES V TEXTURE KIT MOD!
The arms in this folder have been made compatible with the VTK body and texture mods. Make sure that you have installed VTK textures if using these arms.

ALL ARASAKA ARMS REQUIRE A SKIN FILE!
You will find all skins in the Skin Library folder. Each cyberarm type has its own skin file, and they are divided between male and female, left and right arms. It is highly recommended you install the mod with Vortex for easier installation and management.

CLOSED MANTIS ARMS REQUIRE A BLADE MOD!
Only Arasaka Mantis Remade arms open up when used. They can use the default blades. For the rest of the Arasaka Mantis arms you need a blade for closed arms. They can be found in the Blade Library. You can pick different blades between male and female, left and right arms.


ARMS INCLUDED IN THIS FOLDER:

Default = Replaces the normal unmodded arms, and right arm when using Launcher cyberware.
Gorilla = Replaces Gorilla cyberware arms, bought from ripper docs.
Launcher = Replaces Launcher cyberware left arm, bought from ripper docs.
Mantis = Replaces Mantis cyberware arms, bought from ripper docs.
Monowire = Replaces Monowire cyberware arms, bought from ripper docs.

ALL CYBERARM TYPES:
Arasaka Arms -- The normal sized Arasaka Cyberarms.
Arasaka Arms Thin -- Thin version of the normal Arasaka Cyberarms.
Arasaka Arms Forearm -- Forearm only version with a bare upper arm.
Arasaka Kitsch -- The normal sized Arasaka Cybearms with Kitsch nails.
Arasaka Kitsch Thin -- Thin Arasaka Cyberarms with Kitsch nails.
Arasaka Kitsch Forearm -- Arasaka Forearm version with Kitsch nails.

LAUNCHER AND MANTIS ARMS ONLY:
Arasaka Remade -- Arasaka Remade arms that open up like the original cyberarms.
Arasaka Remade Thin -- Thin version of the Remade Arasaka Cyberarms.
Arasaka Remade Forearm -- Forearm version of the Remade Arasaka Cyberarms.
Arasaka Remade Kitsch -- Arasaka Remade arms with Kitsch nails.
Arasaka Remade Kitsch Thin -- Thin Remade cyberarms with Kitsch nails.
Arasaka Remade Kitsch Forearm -- Forearm only version of Arasaka Remade with Kitsch nails.

F = Female
M = Male
L = Left arm
R = Right arm


The files should be placed in the "Cyberpunk 2077\archive\pc\mod" folder. Only place the .archive files there, not the folders.
